사용 가이드
기본 사용법
💬 질문 입력
하단 입력창에 궁금한 위촉 규정을 입력하고 전송하세요. 스마트 검색으로 자동 매칭됩니다.
📂 카테고리 칩
상단 #태그를 클릭해서 카테고리별로 빠르게 검색할 수 있습니다.
⌨️ Enter 키
Enter 키를 눌러서 빠르게 질문을 전송할 수 있습니다.
목록 탭
📋 전체 규정 보기
"목록" 탭을 클릭하면 등록된 모든 규정을 카테고리별로 정렬된 목록으로 볼 수 있습니다.
🏷️ 태그 필터
상단 태그 버튼을 클릭해서 원하는 카테고리만 필터링할 수 있습니다.
📊 정렬 옵션
인기도, 가나다, 최신순으로 규정을 정렬할 수 있습니다.
⭐ 즐겨찾기 필터
☑️ 즐겨찾기만 보기를 체크하면 저장한 규정만 표시됩니다.
고급 기능
⭐ 즐겨찾기
답변 카드의 "저장" 버튼으로 저장하고 즐겨찾기 탭에서 모아보세요.
📋 답변 복사
"복사" 버튼으로 클립보드에 저장해서 다른 앱에 바로 붙여넣기.
🔍 스마트 검색
"신입" → "신인" 같은 유사 단어도 자동으로 매칭됩니다.
🌙 다크모드
헤더 우측 🌙 버튼으로 다크모드를 켜고 끌 수 있습니다.
검색 팁
🎯 짧게 입력
한두 단어로 검색하는 게 가장 정확합니다. 예: "신인", "이직", "채무"
📂 목록에서 찾기
검색이 없으면 "목록" 탭에서 카테고리를 선택해 직접 찾을 수 있습니다.
🔄 관련 규정
첫 번째 답변 후 관련 규정도 자동으로 제안됩니다.
👍 피드백
답변이 도움되었는지 👍/👎 버튼으로 표시해주세요.
